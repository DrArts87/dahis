# NEN 7510 / 7513: maatregelen

NEN 7510 is een managementsysteem voor informatiebeveiliging in de zorg,
gebaseerd op ISO 27001/27002. Certificering is voor één persoon niet
realistisch; dit document legt per relevant thema vast wat we doen. Het is
tegelijk de risicoanalyse die de norm vraagt. Jaarlijks herzien.

## Logging volgens NEN 7513
Per gebeurtenis: tijdstip, gebruiker, actie (`login`, `view`, `create`,
`update`, `delete`, `export`, `print`), record-id, resultaat en apparaat.
Het log staat versleuteld op het toestel en gaat mee in de back-up. Elke
logregel bevat de hash van de vorige, zodat verwijderen of
wijzigen aantoonbaar is. Het log bevat geen namen of medische gegevens.
